# 健身入門 Wiki

這份 Wiki 面向平常較少運動、想開始活動的成年人，整理「一般成人活動建議、如何辨識強度、如何安全開始肌力訓練」。它是教學知識庫，不是個人化訓練或醫療建議。

## 先討論，再生成

**討論問題：**「健身」範圍很大，這份作品要回答新手的哪個問題？讀者是誰？哪些內容需要權威來源？  
**收斂結果：**以一般健康成人新手為讀者，先理解有氧與肌力活動、成人活動量建議、談話測試、入門肌力練習和安全界線；不提供減重保證、補給品建議或疾病治療處方。

## 建立與使用方式

流程是先確定讀者和問題，再擷取來源、整理成來源筆記、交叉檢查數字和適用對象，最後才依 Wiki 產生簡報。簡報中以 `[S01]` 等標籤回鏈來源。來源頁可各自更新；若未來指南更新，先修訂 Wiki 的事實與日期，再重新檢查所有引用該事實的投影片。

本次「ingest」指實際讀取上述五個公開頁面，並把摘要、可用事實和限制整理到本地 Wiki；沒有宣稱使用外部向量資料庫或某個線上 LLM Wiki 服務。

## 使用限制

本 Wiki 主要引用成人公共衛生建議。兒童、孕期、長者、慢性病或身心障礙者的建議可能不同；有疾病、受傷或運動時不適者應先詢問合格醫療專業人員。不要把每週目標當作必須第一週達成的門檻。
